# Fonts

Self-hosted so the page does not wait on Google Fonts where it is blocked.

- `source-serif-4-latin.woff2`, `source-serif-4-latin-italic.woff2`: Source Serif 4 (Adobe), Latin subset, variable weight and optical size. SIL Open Font License 1.1, see `OFL.txt`.
- `source-serif-4-pi.woff2`: Source Serif 4 Greek subset cut down to the single glyph π. Same license.
- `noto-serif-sc-name.woff2`: Noto Serif SC (Google / Adobe), subset to the two characters of the Chinese name. SIL Open Font License 1.1.
