# Fonts

Self-hosted so the page does not wait on Google Fonts where it is blocked.

- `archivo-latin-normal.woff2`, `archivo-latin-italic.woff2`: Archivo, Latin subset, variable weight and width. SIL Open Font License 1.1, see `OFL-Archivo.txt`.
- `source-serif-4-pi.woff2`: Source Serif 4 (Adobe), Greek subset cut down to the single glyph π, used where Archivo has no π. SIL Open Font License 1.1, see `OFL.txt`.
- `noto-serif-sc-name.woff2`: Noto Serif SC (Google / Adobe), subset to the two characters of the Chinese name. SIL Open Font License 1.1.
