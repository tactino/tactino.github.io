# Personal Academic Website

This folder contains the source code for your personal academic website.

## How to use with GitHub Pages

1.  **Create a Repository:**
    *   Go to GitHub and create a new repository named `username.github.io` (replace `username` with your actual GitHub username, e.g., `Gotham-Zolio.github.io`).

2.  **Upload Files:**
    *   Upload `index.html` and `style.css` to the root of that repository.
    *   (Optional) Add a photo of yourself named `profile.jpg` to the repository.

3.  **Visit your site:**
    *   Your website will be live at `https://username.github.io`.

## Customization

*   **Photo:** Replace `profile.jpg` with your own photo.
*   **Content:** Edit `index.html` to update your news, publications, or research descriptions.
*   **Style:** Edit `style.css` to change colors, fonts, or layout.
