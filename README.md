# Zuo Gou Personal Academic Website

Source of https://tactino.github.io, served by GitHub Pages from `main`.

## Structure
- `index.html`: the page.
- `style.css`: all styles.
- `cv.pdf`: a copy of the current CV.
- `profile.jpg`: the portrait; the night-blue `--night` colour in `style.css` matches its background.
- `fonts/`, `images/`, `media/`: self-hosted fonts, images and video clips. Sources and licenses are in `CREDITS.md`.
- `papers/`: the workshop paper's PDF, kept for old links; the page links to arXiv.
